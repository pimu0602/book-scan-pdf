# Paper to AI

紙の本、ノート、資料などをブラウザだけで撮影・整理してPDFにし、そのPDFをAIで活用するための依頼文まで作成できる静的Webアプリです。

この版は `paper-to-ai` ブランチで開発しています。既存のBook Scan PDFは別ブランチに残しています。

## 使い方

1. `index.html` をブラウザで開く、またはローカルサーバーで配信します。
2. `画像を選択` で端末内の画像を複数追加できます。
3. スマートフォンでは `カメラで撮影` で連続撮影できます。
4. `ページ確認` で削除・上下移動を行います。
5. PDFレイアウトを選びます。
6. PDFファイル名を入力して `PDFを作成` または `PDFを共有` を押します。
7. PDF作成後に `AI依頼文を作る` を押します。
8. 用途、対象者、出力形式、追加条件を選んで依頼文を生成します。
9. 生成された依頼文をコピーし、PDFと一緒にAIへ渡します。

PDFレイアウトは3種類あります。

- `通常`: 画像の向きに合わせてA4にフィットします。
- `自動補正`: 写真内の紙面を自動検出し、台形補正と白黒寄りの明るさ補正をしてA4縦に配置します。
- `裏写り軽減`: 写真内の紙面を自動検出して真っ直ぐに補正し、薄い裏写りを白に近づけてA4縦に配置します。

自動補正は、紙と背景の明るさに差がある写真ほど安定します。紙面を検出できない場合は、元画像を使ってPDF化します。
裏写り軽減で紙面を検出できない場合は、文字や線の傾きを推定して軽く回転補正し、元画像全体に裏写り軽減をかけます。薄い印刷やグレー線も消える場合があるため、通常モードと比較して使い分けてください。
カメラ撮影では、画面に表示されている範囲に合わせて画像を保存します。
通常起動時はページ一覧を初期化します。PDFプレビューから戻った時だけ、直前のページ一覧、PDFレイアウト、ファイル名をブラウザ内ストレージから復元します。

## AI依頼文

AI APIは使用せず、選択内容と内蔵テンプレートを組み合わせて依頼文を生成します。

- 用途: 要約、手順書、チェックリスト、用語解説、注意点、教育資料、SNS投稿、画像生成プロンプト
- 対象者: 自分、初心者、新人、現場作業者、お客さん、SNS読者
- 出力形式: 箇条書き、表、手順、チェックリスト、説明文、投稿文、画像生成用プロンプト
- 追加条件: 専門用語、現場向け、重要度、事実と推測、機密情報、ミスやつまずきなど

生成後はコピー、直接編集、再作成ができます。

カメラ機能はスマートフォン専用です。PC・タブレットでは画像選択からPDF化します。
スマートフォンのカメラ機能はブラウザの制約により、HTTPSまたは `localhost` / `127.0.0.1` での配信が必要になる場合があります。

ローカルサーバーで起動する場合:

```bash
node dev-server.js
```

起動後に `http://127.0.0.1:4173` を開きます。

## 構成

- `index.html`: 画面構成
- `styles.css`: レスポンシブUI
- `app.js`: 画像管理、カメラ撮影、PDF生成
- `dev-server.js`: ローカル確認用の静的サーバー

画像やPDFデータは外部サーバーへ送信せず、端末内のブラウザで処理します。
共有するときはアプリのURLではなく、作成されたPDFファイルを共有します。
